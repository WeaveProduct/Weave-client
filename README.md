## Какие ключи поддерживаются

WeaveVPN работает **только с подписками WeaveVPN**. Получить ключ — в Telegram-боте
**[@WeaveVPNBot](https://t.me/WeaveVPNBot)**.

Войти в приложение можно двумя способами:

- **через Telegram** — кнопка на экране входа, подтверждение в боте;
- **по ссылке подписки** (`https://client.weavevpn.ru/…`) или по коду из бота.

Ключи и подписки других VPN-сервисов приложение не принимает.

## Возможности

- Подключение в одно касание и автовыбор самого быстрого сервера
- Резервный сервер и Kill Switch — VPN не пропадает, если сервер перестал отвечать
- Маршрутизация: российские сайты напрямую, остальное через VPN; свои правила для приложений и сайтов
- Виджет и плитка в шторке на Android, значок в трее на Windows
- Избранные серверы, поиск, сортировка по пингу
- Статистика трафика по дням и месяцам, выбор DNS

## Установка

**Android.** Скачайте APK и откройте его. Если телефон спросит — разрешите установку из этого источника.

**Windows.** Распакуйте архив в любую папку и запустите `WeaveVPN.exe`. Для режима TUN (весь трафик
компьютера) нужны права администратора — приложение само предложит перезапуститься с ними.
